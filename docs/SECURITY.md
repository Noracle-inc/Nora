# Noracle Security Notes

## Security boundaries

- Keep secrets only on the server.
- Validate all user input.
- Use server-side authorization for protected actions.
- Avoid storing sensitive user text in client-side storage.
- Use HTTPS in production.
- Log metadata, not message content.

## Data minimization

- Only retain the data needed to support the feature.
- Let users view, correct, export and delete their personal data.
- Keep guest mode ephemeral and clearly labelled.
